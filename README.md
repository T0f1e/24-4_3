# Project Goal
Создать веб-приложение для руководителей и сотрудников организаций, позволяющее удобно составлять рабочие графики, распределять смены и контролировать рабочее время.

## Инструкция по запуску

### Требования
- Установленный Node.js (версия 16 или выше)

### Установка

1. Клонируйте репозиторий:
   git clone https://github.com/T0f1e/24-4_3.git
   cd 24-4_3

2. Установите зависимости:
   npm install

### Запуск

В корне проекта выполните:
node index.js

В терминале появится сообщение:
Сервер запущен: http://localhost:3000

Откройте в браузере: http://localhost:3000

### Первый вход

1. Нажмите вкладку «Регистрация».
2. Заполните имя, email и пароль (минимум 6 символов).
3. Первый зарегистрированный пользователь автоматически получает роль «Руководитель» и доступ к управлению сотрудниками.
4. Последующие пользователи будут создаваться с ролью «Сотрудник».

### Остановка сервера

В терминале, где запущен сервер, нажмите Ctrl + C.

### Технологии

- Backend: Node.js, Express, SQLite (better-sqlite3), bcryptjs, JWT
- Frontend: Vanilla JavaScript, HTML5, CSS3
.
